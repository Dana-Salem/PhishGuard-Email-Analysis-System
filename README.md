# PhishGuard Email Analysis System

PhishGuard is an automated phishing email analysis and risk scoring system developed as part of an Information System Security project.

## Project Overview

The system analyzes `.eml` email files and extracts suspicious indicators from email headers, domains, URLs, and attachments. Based on the extracted indicators, the system calculates a risk score and classifies the email as Allow, Quarantine, or Block.

## Main Features

- Email parsing and indicator extraction
- Header, domain, URL, and attachment analysis
- Risk scoring from 0 to 100
- Email classification: Allow, Quarantine, or Block
- Explainable report showing suspicious indicators and final decision

## Technologies Used

- Python
- Static analysis tools
- DNS and WHOIS lookup tools
- PDF and Office attachment analysis tools
